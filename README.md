# דף נחיתה – תוכנית ליטיגציה, עו"ד שי רשף

## איך ממשיכים בקלוד קוד
1. לחלץ את התיקייה למחשב
2. לפתוח טרמינל בתוך התיקייה ולהריץ `claude`
3. קלוד קוד קורא את `CLAUDE.md` לבד ומקבל את כל ההקשר. אפשר להתחיל, למשל:
   - "הכנסתי תמונות לתיקיית images, תעדכן את הדף"
   - "תחבר את הטופס ל-Google Sheets"
   - "תעלה את הדף ל-Netlify"

## צפייה מקומית
לפתוח את `index.html` בדפדפן, או להריץ `npx serve .`

## לפני עלייה לאוויר
1. **תמונות:** לפי `images/README.md`
2. **טופס:** לפי `integrations/google-sheets-apps-script.gs`, ואז להדביק את ה-URL ב-`LP_CONFIG.webhookUrl` שב-`index.html`
3. **פיקסל:** להדביק את מזהה הפיקסל ב-`LP_CONFIG.metaPixelId`
4. **טקסטים:** לחפש `[` בקבצים ולהשלים את כל ה-placeholders
5. **פרטיות ונגישות:** לאשר עם שי
