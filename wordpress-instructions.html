הטמעת דף הנחיתה "ליטיגטור" בוורדפרס

הדף מוכן ומאושר. צריך להטמיע אותו באתר reshef-adv.co.il, לחבר אותו לטופס של האתר ולפיקסל הקיים, ולוודא שכל ליד מגיע לשי ומדווח למטא כ-Lead.

איך הדף צריך להיראות: https://reshef-landing-production-05c1.up.railway.app/

הקבצים: בתיקייה הזו. index.html הוא הדף כולו (CSS ו-JS בתוך הקובץ), ותיקיית images/ מכילה את התמונות.

1. עמוד חדש בתבנית ריקה

  1. יוצרים עמוד חדש, למשל בכתובת /litigator.
  2. תבנית: ריקה, בלי header ו-footer של האתר (למשל Elementor Canvas, או "Blank" / "Full width, no header" בתבנית). לדף יש header ו-footer משלו. בלי תבנית ריקה, ה-CSS של הדף והתבנית יתנגשו.
  3. מעלים את התמונות מתיקיית images/, ב-FTP לתיקייה /wp-content/uploads/litigator/images/ או לספריית המדיה.
  4. ב-index.html מחליפים את כל המופעים של images/ בכתובת שאליה העליתם. למשל: /wp-content/uploads/litigator/images/.

2. הדבקת הדף

  1. מעתיקים מ-index.html את כל מה שבין <head> ל-</body>, חוץ מבלוק הפיקסל (ראו סעיף 4), ומדביקים לבלוק Custom HTML או לווידג'ט HTML של Elementor.
  2. צריך משתמש עם הרשאת unfiltered_html (מנהל), אחרת וורדפרס מוחק את תגי ה-<script>.
  3. בודקים שהדף נראה כמו בקישור למעלה, במחשב ובנייד.

3. הטופס: מחליפים את הטופס שלנו בטופס של האתר

בדף, הטופס יושב בתוך <section id="form">. מחליפים רק את האלמנט <form id="lead-form">…</form> בטופס של האתר (Elementor Form, Contact Form 7 וכו').

  • לא משנים את ה-id="form" של ה-section: כל כפתורי הדף מובילים אליו.
  • הקוד של הדף בנוי לעבוד גם כשהטופס שלו לא קיים.

מילוי השדות הנסתרים (UTM)

הדף שומר את פרמטרי ה-UTM מהכתובת. ב-Elementor אפשר למלא כל שדה נסתר עם Dynamic Tag מסוג Request Parameter. בכל טופס אחר, מדביקים את הקוד הזה מתחת לטופס, והוא ממלא כל שדה ששמו utm_source וכו':

<script>
(function(){
  var keys=["utm_source","utm_medium","utm_campaign","utm_content","utm_term","fbclid"];
  var qs=new URLSearchParams(location.search), saved={};
  try{ saved=JSON.parse(sessionStorage.getItem("lp_attr")||"{}"); }catch(e){}
  keys.forEach(function(k){
    var v=qs.get(k)||saved[k]||"";
    document.querySelectorAll('input[name="'+k+'"],input[name="form_fields['+k+']"]')
      .forEach(function(i){ i.value=v; });
  });
})();
</script>

אחרי שליחה מוצלחת

  1. מייל לשי עם כל השדות, כולל ה-UTM.
  2. שמירה של כל ליד: Elementor Submissions, Flamingo ל-CF7, או גיליון.
  3. הפניה לדף תודה: יוצרים עמוד תודה עם התוכן של thanks.html, ומסמנים אותו noindex.
  4. אירוע Lead למטא: הכי פשוט ובטוח זה לשים בדף התודה בלבד: 
    <script>if (window.fbq) fbq('track','Lead');</script>
    אם אין דף תודה, ב-Contact Form 7: 
    <script>
document.addEventListener('wpcf7mailsent', function(){
  if (window.fbq) fbq('track','Lead');
  setTimeout(function(){ location.href='/litigator-thanks/'; }, 300);
});
</script>

4. פיקסל מטא

  • האתר כבר טוען את הפיקסל של שי, ואותו פיקסל ממשיך לשמש את הדף.
  • בראש index.html יש בלוק <!-- Meta Pixel -->. לא מדביקים אותו, כדי שהפיקסל לא ייטען פעמיים. משאירים את metaPixelId ריק ב-LP_CONFIG.
  • הדף שולח לבד גם אירועים מותאמים דרך הפיקסל של האתר: CTAClick (לחיצה על כפתור) ו-FormStart.
  • האירוע שהקמפיין מתבסס עליו הוא Lead (סעיף 3).

5. תמונת שיתוף

בהגדרות ה-SEO של העמוד (Yoast / RankMath), מגדירים את תמונת השיתוף ל-images/og.jpg בכתובת מלאה. כותרת השיתוף: "כבר מנהל תיקים בבית המשפט. אבל מי לימד אותך איך לנהל אותם נכון?"

6. בדיקה לפני שמפעילים קמפיין

הקמפיין עולה ביום ראשון, 1.11. אנחנו צריכים את כל הבדיקות האלה עד יום חמישי, 29.10.
  • הדף נראה כמו בקישור, במחשב ובנייד, בלי גלילה הצידה
  • כל הכפתורים גוללים לטופס
  • ליד ניסיון דרך הכתובת /litigator/?utm_source=test&utm_campaign=check: מגיע לשי במייל, עם utm_source=test
  • אחרי שליחה, הדף עובר לדף התודה
  • ב-Meta Events Manager ← Test Events: מופיעים PageView ו-Lead, כל אחד פעם אחת בלבד
  • תיבת ההסכמה לא מסומנת מראש, ובלי לסמן אותה אי אפשר לשלוח
  • הקישורים למדיניות הפרטיות ולהצהרת הנגישות בתחתית הדף עובדים

מה לא לשנות

הטקסטים, העדויות והעיצוב אושרו על ידי שי. אין להוסיף מחיר לדף. כל שינוי בתוכן עובר דרך יובל.
