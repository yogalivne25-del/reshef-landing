# תמונות לדף

שמות הקבצים חייבים להיות בדיוק כאלה. כל עוד קובץ חסר, הדף מציג במקומו placeholder.

| קובץ | מה | גודל מומלץ |
|---|---|---|
| `shai-hero.jpg` | שי "בפעולה": מדבר מול אנשים, מצביע על מסמך, חדר ישיבות | 1200×1500 (4:5), עד 300KB |
| `shai-portrait.jpg` | פורטרט נקי, חליפה, מבט למצלמה | 1200×1500 (4:5), עד 300KB |
| `og.jpg` | תמונת שיתוף לוואטסאפ ולפייסבוק | 1200×630 |
| `logo.svg` | לוגו, רקע שקוף (אם יש) | SVG או PNG |

לפני העלאה: לדחוס ב-squoosh.app או tinypng.com.
